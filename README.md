مشروع UniAccounts

نظام إدارة حسابات الطلبة باستعمال Design Patterns بلغة Java
1. مقدمة عن المشروع

مشروع UniAccounts هو نظام بسيط لإدارة حسابات الطلبة في الجامعة، تم تطويره باستعمال لغة البرمجة Java.

الهدف من المشروع هو تنظيم عملية إنشاء حسابات الطلبة وتخزينها في مستودع مركزي، مع تسجيل العمليات التي تتم على الحسابات في سجل خاص يسمى Audit Log.

يعتمد العمل الأول من المشروع على ثلاثة أنماط تصميم إنشائية (Creational Design Patterns):

Builder Pattern

Singleton Pattern

Prototype Pattern

كل نمط من هذه الأنماط يحل مشكلة معينة في طريقة بناء الكائنات وتنظيمها
ببساطة، الجامعة تحتاج برنامج تقدر من خلاله تنشئ حسابات الطلبة، تخزنهم في مكان واحد، وتسجل العمليات اللي تصرا عليهم.
